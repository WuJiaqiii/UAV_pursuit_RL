# UAV pursuit RL · v7.0.0

使用直接 CTBR（总推力与机体系角速度）进行持续飞行和机动目标追踪。物理积分为 **1 kHz**，默认网络决策为 **100 Hz**。主入口为 main.py。

## 本版变化

- **因果预测**：40 帧目标运动历史，预测未来 50/100/200 ms 的目标位移；小型 LSTM 学习恒加速度预测的残差。预测结果进入 Actor 和 critic。预测器在每次 PPO 采样、更新期间冻结，随后单独监督训练。
- **两个时钟**：每条 CTBR 保持 10 ms；动力学、执行器响应、安全检查及末段指标每 1 ms 更新。奖励按物理子步折扣累计，gamma、GAE、探索相关性使用决策周期。
- **34 级课程**：从悬停、平飞到近距弱机动，再扩大机动、距离和速度。已有能力先筛查，可跳过已掌握课程；通过两组验证与旧技能精度门槛后可提前升级。
- **ValueNorm**：归一化价值目标，GAE 与 MC 仍使用奖励单位；统计改变时重标定输出头，保持原单位下的估值连续。
- **持续 MC 纠偏**：默认每 16 次 PPO 更新，使用当前冻结随机策略采集完整回合，仅拟合 critic；独立校准验证集检查退化并决定是否回滚。归一化统计和三个优化器均保存到检查点。
- **旧技能采样**：训练默认分配约 60% 环境给当前任务，20% 给上一课程，20% 给一个轮换保留任务；所有动作均由当前策略重新生成。

基础课程保留教师 BC/DAgger 初始化；第 05 级起默认不再进行教师迁移拟合。日志和检查点区分初始化、PPO 改进与跳过课程。

本版使用 v3 配置和检查点契约。v690/v691 检查点不能直接恢复或迁移到本版；请使用新的实验目录，保留旧实验用于对照。训练有效性仍需正式多种子实验验证。

## 安装与快速检查

Python 3.10+，PyTorch 2.1+。按服务器的 CUDA 环境安装 PyTorch 后：

~~~bash
pip install -e '.[dev]'
pytest -q
python main.py train --config configs/ctbr/smoke.json --out runs/v700_smoke --device cpu
~~~

smoke 是短时程序检查，不代表正式 20–60 秒任务通过。

## 训练

先运行一个种子：

~~~bash
SEEDS=42 DEVICE=cuda PYTHON_BIN=python bash scripts/run_ctbr_curriculum.sh runs/ctbr_v700
~~~

默认完整课程；每级 2000 万物理步是预算上限，已掌握课程会跳过，通过门槛可提前升级。确认 seed 42 后可运行 SEEDS="42 43 44"；已有相同配置的种子会继续或复用已完成阶段。

中断后用完全相同的命令和目录继续。课程程序会检查源代码、父模型、配置与采样任务的一致性。失败门槛不会自动降低。

单项实验及具体输出见 [实验操作](docs/EXPERIMENTS.md)。模型与数据流见 [架构](docs/ARCHITECTURE.md)，本地核查边界见 [验证记录](docs/VALIDATION.md)。
