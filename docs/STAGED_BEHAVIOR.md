# 分段 DAgger 诊断

上一轮候选在 384 个验证回合中全部因倾角超限终止。使用相同的 A、训练场景、采样种子、学习率与小批次种子，比较无约束和有约束两组。约束组增加对 A 的执行动作均方误差，权重为 1，作为首轮对照值。

在项目根目录和 airsim 环境运行：

```bash
for weight in 0 1; do
  python -m pursuit_rl.ctbr.staged_behavior \
    --checkpoint runs/ctbr_v701/seed_42/initializations/A.pt \
    --out "runs/staged_v704_anchor_${weight}" --device cuda \
    --anchor-weight "$weight" --milestones 10 25 50 100
done
```

每组从 A 开始，沿同一条 Adam 更新轨迹保存第 0、10、25、50、100 次权重。训练样本由 A 在机动任务上执行 32 个完整回合采集。固定状态从独立种子的 A 悬停和 1 m/s 匀速回合采集。每个候选在相同的 8 个悬停、8 个匀速回合进行快速筛选。约束比较应保持设备、场景和参数一致，可通过保存的张量核对两组输入。

- `manifest.json` 保存参数、场景、种子、源码和基线权重指纹。
- `training_samples.pt`、`fixed_*.pt` 保存完整输入和 teacher 标签，固定状态额外保存 A 的执行动作。
- `updates.jsonl` 保存每次更新的模仿损失、约束损失和裁剪前梯度范数。
- 每个 `update_*/` 保存候选、固定状态上的逐样本动作、逐轴误差、完整筛选回合结果以及约 20 ms 采样的轨迹。轨迹包含位置、归一化动作、姿态矩阵、实际机体角速度和推力。倾角可由 acos(rotation[...,2,2]) 计算，终止时间和原因以回合记录为准。
- `summary.json` 标记进入完整验证的更新点，以及通过原防退化门槛的候选路径。每组从筛选成功率未下降的候选中挑选 1 m/s 末段 RMSE 最低者，随后在原六类任务、两个种子上完整验证。selected 为 null 表示该组未选出候选。

对照每个更新点的失稳时刻和逐轴动作变化。如果模仿误差下降但倾角更早超限，检查失稳前的横滚、俯仰指令和实际角速度。如果约束组保持稳定但 1 m/s 误差无改善，应比较更早候选的动作变化和同状态探针，再决定是否增加训练样本覆盖。

通过门槛的候选用已有 diagnostics 入口和新种子 1210042、1310042 与 A 配对验收，每种子 64 回合，开启 --stochastic。也可用 behavior probe 复查该候选在 1 m/s 末段的平衡点。候选检查点用于评估或 --init-from，优化器不作为续训状态保存。
