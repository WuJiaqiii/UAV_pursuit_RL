# 本地验证范围

## 6.9.1 初始化修复（2026-10-30）

服务器部分结果已核验：seed 42 初始 0/64（61 次 tilt、3 次 outside），2000 万步、153 次 PPO 更新后仍无成功训练回合；seed 43 初始也为 0/64。旧版 BC 损失很低仍然闭环失稳，DAgger 没有验收保护，软件短测试不能替代学习策略完整飞行验证。

修复后自动测试 26 项通过，1 项 CUDA 测试跳过；新增监督片段重采样、无关输入屏蔽、标准化折叠、DAgger 回退、初始化提前停止与恢复防绕过、空窗口 null、v690 checkpoint 兼容、门槛退出无 traceback，以及稀有初始状态 critic 拟合检查。

CPU 实验保持原来的 20 秒持续悬停定义与 0.75 m 半径。seed 43/44 的学习网络在独立种子 79043/79044 上分别通过 64/64 回合，末尾位置 RMSE 约 0.0132/0.0066 m。seed 42 在固定验证种子上的初始化为 64/64，约 0.0208 m；在独立种子 79042 上最佳模型也为 64/64，约 0.0200 m。

在相同合格 actor 与 MC 测试种子下，初始状态的分层采样将独立 MC 初始状态 RMSE 从约 0.880 降至 0.061；生产预热流程为 0.044。随后执行 1,048,576 条 PPO 转移（8 个 rollout 更新、每环境 32.768 秒），32/32 个已完成训练回合成功，完整验证为 64/64；末尾位置 RMSE 约 0.258 m，独立随机策略 MC RMSE 为 0.085、偏差 0.079。**PPO 后位置误差高于初始化，因此 best 保留初始化，不能声称 PPO 已提升性能。**

这些是 CPU 上的基础悬停修复与短程 PPO 检查，不代表服务器 CUDA 或十阶段高机动课程已经验证。
